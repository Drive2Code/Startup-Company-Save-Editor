# Редактор сохранений для Startup Company

**Save Editor for Startup Company**

Программа для редактирования файлов сохранения игры **Startup Company**. Позволяет изменять баланс, очки исследований, параметры сотрудников, инвентарь и многое другое.

![Скриншот главного окна](screenshots/main_window.png)  
*Пример интерфейса (скриншот)*

---

## 🚀 Возможности

- 📊 **Баланс** и **очки исследований** – мгновенное изменение.
- 👥 **Сотрудники** – редактирование скорости, максимальной скорости, зарплаты, настроения и графика работы.
- 📦 **Инвентарь** – просмотр и изменение всех компонентов (план и склад).
- 💰 **Транзакции** – просмотр последних операций.
- ✂️ **Копирование/вставка** значений в таблицах (Ctrl+C / Ctrl+V).
- 🌍 **7 языков** – русский, английский, украинский, французский, испанский, корейский, упрощённый китайский.
- 📁 **Автоматический поиск папки с сохранениями**.
- 🖼️ **Кастомная иконка** для окна и исполняемого файла.
